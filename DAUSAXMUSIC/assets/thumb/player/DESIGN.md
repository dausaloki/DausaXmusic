# DausaXmusic playback thumbnail assets

`dausaxmusic-cyan-reference.png` is the approved visual direction for the new
Black + Cyan Neon player branding. The runtime thumbnail renderer still creates
song-specific cards from real track artwork and requester information; this
reference image is not sent as a static song card.

`cinematic-template.png` remains as the neutral rendering plate used by the
dynamic renderer. The renderer uses the actual song artwork and requester
photo where available and generates the title, progress and waveform details
at runtime. No image-generation service is called during playback.

The approved visual direction uses a dark cinematic background, cyan lighting,
clear typography and restrained glass/neon elements.
